# V2 人工图像复核记录

本轮逐张使用 Read 打开实际 PNG，不以日志成功代替看图。五个最终主图均已打开；面部 200%、低墙 300%、门窗接缝与坐桌接触另开局部图放大检查。

## 已实际看图后再迭代的问题
1. 第一版区域比例改造后出现肩头球结；尝试肩骨权重后又出现尖刺。均未采用，改成自然垂臂的绑定静态姿势，重新连通衣袖与胸身，再归一化肩肘权重。
2. 第一版眼睛位置偏高且显得眯眼；重新画 2048² 眼白、虹膜与双高光，调整眉鼻嘴及腮红位置。最终面部正面 200% 逐像素图清楚，表情为平静微笑。
3. 第一版刘海锁块过凸；压扁并内收，使其不再像额前伸出的圆棒，同时 Idle 头部略抬，45° 能看到五官。
4. 睡姿世界空间比例映射导致颈头压缩；改在局部比例空间完成姿态旋转，并补充真实可导出的 SleepLids 闭眼 morph。
5. 接触测量曾发现左手空握书约 55mm、头不在枕面上；修正左腕/掌目标、睡姿整体位置，并按男女发型分别修头颈高度后复测。最终数据见 contact_qc_v2.json。
6. 低墙原黑端来自共面交叠，裁掉角接实例交叠而不是调亮掩盖；300% 角部检查无旧黑块，保留正常拼接线。
7. 看暖亮房间全图时发现额外门框黑接缝、窗框小黑点；保留修复前局部图，再缩短门立柱和拆分窗横框净跨，从几何上消除共面交叠。修复后的门窗放大图已 Read，黑缝消失。
8. Godot 第一版白色织物高光过曝；降低 Directional/Omni/ambient，并给亚麻做曝光补偿，最终枕头/地毯可读且室内保持日间暖色。
9. 第一张最终拼板的 45° 男角色鞋被画幅裁掉；重新扩大相机正交范围，只重渲该视图。最后再次 Read 01 图，两人全身及鞋底均完整入镜。

## 不夸大的边界
- 仍为 4.71 头身的简化生活模拟卡通造型，不是写实/电影级精雕；手部为简化掌形与拇指，21 骨中没有独立指骨。
- BVH 最近表面距离验证的是接触位置，不代表自动证明全身体积永不自相交；同时做图像检查。
- 旧茶几极小倒角三角的诊断如实保留在报告；人物为零退化、所有导出为零重复索引面。
- 最终审美验收由用户决定；本轮未改游戏仓库，也不推进城市建筑验收。
