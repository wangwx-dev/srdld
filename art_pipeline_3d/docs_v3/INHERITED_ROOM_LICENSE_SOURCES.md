# Opened license sources (2026-11-13, Asia/Shanghai)

- https://polyhaven.com/license — all asset HDRIs, textures and 3D models CC0; commercial use and redistribution allowed. Website renders/logos are not included in this permission.
- https://polyhaven.com/llms.txt — use API, send identifying User-Agent, use MD5 from file metadata. Downloading code in source/download_assets.py uses this pattern.
- https://api.polyhaven.com/files/{asset} — exact file URL, size and MD5 copied into asset_manifest.json and raw evidence/*_files.json.

No Poly Haven website preview renders were used as generated game assets. The project previews were rendered locally from actual mesh geometry and downloaded textures.
