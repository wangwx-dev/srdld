## 再生成
1. `python3 source/make_material_textures.py && python3 source/make_albedo_textures.py`
2. `blender -b --python source/build_v3.py`（相邻 V2 工程为只读输入）
3. `blender -b --python source/render_v3.py -- studio`；另一次运行 `-- room`；对比基线运行 `-- v2`。
4. Godot 工程导入新 GLB 后执行 `--rendering-method gl_compatibility --script render_v3.gd`。
5. 运行 source/audit_v3.py、source/contact_qc_v2.py、source/verify_glb.py，再运行 make_boards_v3.py 和 write_report_v3.py。
